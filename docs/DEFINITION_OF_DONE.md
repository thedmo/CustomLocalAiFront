# Definition of Done (DoD)

Ein Use Case gilt als abgeschlossen, wenn:

- [ ] alle Akzeptanzkriterien erfüllt sind.
- [ ] Code ausführbar bzw. buildbar ist.
- [ ] Coding-Guidelines eingehalten sind.
- [ ] automatisierte Tests erfolgreich sind.
- [ ] relevante manuelle Tests durchgeführt wurden.
- [ ] keine Secrets, persönlichen Daten oder lokalen Pfade eingecheckt wurden.
- [ ] neue Abhängigkeiten geprüft und dokumentiert sind.
- [ ] notwendige Dokumentation aktualisiert ist.
- [ ] menschliches Review erfolgt ist.
- [ ] bekannte Einschränkungen oder Restpunkte dokumentiert sind.

Architektur-, Sicherheits- oder schwer nachvollziehbare Änderungen benötigen ein explizites Review durch ein anderes Teammitglied.
