# CustomLocalAiFront

## Voraussetzunen

Damit die Modell anbindung benutzt werden kann, müssen folgende Voraussetzungen erfüllt sein:

- Docker installiert

- Docker Model Runner aktiviert

- pull_models.sh ausgeführt (einfaches skript, welches die nötigen Modelle herunterlädt)

## Starten

Ins Projektverzeichnis wechseln

Service starten per `Docker Compose up -d`

Aufrufen via `http://localhost:3000`
